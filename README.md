# Student Management System

A beginner-friendly Student Management System built with Python and JSON file handling.

## Features

* Add Student
* View All Students
* Search Student by ID
* Update Student Information
* Delete Student Records
* Data stored permanently using JSON

## Technologies Used

* Python
* JSON
* File Handling
* Functions
* Exception Handling

## How to Run

1. Download the project.
2. Open Terminal or Command Prompt.
3. Navigate to the project folder.
4. Run:

```
python studentManagement.py
```

## Learning Objectives

This project was created to practice:

* Python dictionaries
* JSON (`load` and `dump`)
* File handling
* Functions
* Loops
* Conditional statements
* Error handling
